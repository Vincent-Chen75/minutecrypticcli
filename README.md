# Minute Cryptic CLI

## Installation

- Download this repository
- Create a python environment and enter it
- Install the requirements with requirements.txt
- Launch either
  - scraper.py to scrap the Minute Cryptic clue of the day
  - game.py to launch the game in the CLI
